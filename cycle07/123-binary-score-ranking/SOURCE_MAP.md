# 公式与官方源码（2026-11-08）

- [Geifman 与 El-Yaniv，NeurIPS 2017，第二节式 1、3](https://proceedings.neurips.cc/paper/2017/file/4a8423d5e91fda00bb7e46540e2b0cf1-Paper.pdf)。接受率与条件错误率沿用论文定义；run.py/main 独立统计经验前缀，无论文代码复制。三分数的单调性证明为本文推导。run.py/scores 独立实现减最大值的 softmax、自然熵与绝对原始 logit 差，audit.py 用 Decimal 和直接子集求和交叉验证；plot.py 读取 ranking.json。
