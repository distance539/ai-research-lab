# 源码地图（访问 2026-11-17）
- 模型：Hugging Face Transformers 4.49.0，Apache-2.0。[DistilBertForSequenceClassification.forward，第918–991行](https://github.com/huggingface/transformers/blob/a22a4378d97d06b7a1d9abad6e0086d30fdea199/src/transformers/models/distilbert/modeling_distilbert.py#L918-L991)。已取固定提交文件与实际安装文件逐字节 cmp 相等，SHA-256 为 7aa246bf0a4b45f901b83a9ab993e7dd2c0fb91f4fbb874045baec8ae7429a6e。run.py 调用官方类，不复制网络结构。模型与 tokenizer 共用 [714eb0f](https://huggingface.co/distilbert/distilbert-base-uncased-finetuned-sst-2-english/tree/714eb0fa89d2f80546fda750413ed43d93601a13)，五文件哈希在 resources.lock.json。
- 标量温度与损失：Guo 等 [ICML 2017 §4.2](https://proceedings.mlr.press/v70/guo17a.html)。run.py:score 独立按二元分数差计算，audit.py 用两列 softmax 复算，非论文代码移植。直接沿用[固定源实验](https://github.com/distance539/ai-research-lab/tree/f33e57cca855c0d2c6da5aed4753de76db0e7a89/cycle07/117-temperature-scaling)的 fit.json、audit_predictions.json 与 resources.lock.json。SST-2 卡片许可 unknown，不附原句。
- 划分：run.py:scan 独立教学实现；IMDb v1 tar 内 README 定义 test/urls_pos.txt 和 test/urls_neg.txt 与文件序号的映射。依据[作者论文](https://aclanthology.org/P11-1015/)及 [TFDS checksums](https://github.com/tensorflow/datasets/blob/master/tensorflow_datasets/datasets/imdb_reviews/checksums.tsv)核对版本。原包未给出影评全文可再分发许可；不采用镜像自报许可。仅分发哈希与派生预测。作者自写脚本 MIT，框架许可证另附。
- 固定阈值计数、等宽分箱、类别求和 Brier 与 plot.py 都是独立实现；未调用上游的校准度量函数，因而没有相应的上游行号。
