# Source map • inspected 2026-11-06

- SmolLM2 next-token score: Transformers 4.49.0, commit a22a4378d97d06b7a1d9abad6e0086d30fdea199, Apache-2.0. [LlamaForCausalLM](https://github.com/huggingface/transformers/blob/a22a4378d97d06b7a1d9abad6e0086d30fdea199/src/transformers/models/llama/modeling_llama.py#L752) and [vocabulary projection](https://github.com/huggingface/transformers/blob/a22a4378d97d06b7a1d9abad6e0086d30fdea199/src/transformers/models/llama/modeling_llama.py#L859). score.py calls the installed official class; we independently select the final position and the two one-token continuations. [Checkpoint and tokenizer](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct/tree/12fd25f77366fa6b3b4b768ec3050bf629380bac) Apache-2.0, exact hashes in model.lock.json.
- C inputs came from the [117 implementation](https://github.com/distance539/ai-research-lab/tree/f33e57cca855c0d2c6da5aed4753de76db0e7a89/cycle07/117-temperature-scaling) invoking [DistilBertForSequenceClassification L918](https://github.com/huggingface/transformers/blob/a22a4378d97d06b7a1d9abad6e0086d30fdea199/src/transformers/models/distilbert/modeling_distilbert.py#L918), same framework commit/license. [DistilBERT checkpoint](https://huggingface.co/distilbert/distilbert-base-uncased-finetuned-sst-2-english/tree/714eb0fa89d2f80546fda750413ed43d93601a13), Apache-2.0. run.py uses its fixed logits. Source package includes needed numeric inputs; original text available only from [Stanford SST2](https://huggingface.co/datasets/stanfordnlp/sst2/tree/8d51e7e4887a4caaa95b3fbebbf53c0490b58bbb), license unknown. resources.lock.json records hashes.
- Temperature division and held-out fitting: [Pleiss et al. temperature_scale and set_temperature L23–83](https://github.com/gpleiss/temperature_scaling/blob/ce1154ec7d5235eee046f28875c3dd8421f11d45/temperature_scaling.py#L23), MIT. [Guo et al., ICML 2017](https://proceedings.mlr.press/v70/guo17a.html). Independent run.py fit (bounded inverse-temperature gradient bisection) and metrics (binary stable softplus); audit.py independently minimizes loss over T, not the derivative. No author code copied. Cross-application matrix and fixed order swap are our experiment.
- prepare.py and resource locks originate in the author's 116 implementation and package LICENSE; neural libraries/models/data are fetched separately, not relicensed. plot.py uses Matplotlib on measured result.json. All three methods read the same labels; candidate log scores admit the same temperature arithmetic but describe a conditional two-answer event.
