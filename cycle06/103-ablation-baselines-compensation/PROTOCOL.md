# Frozen protocol — 2026-10-19, before inference

Question: do END-only ablation drops and nonadditivity depend on the reference baseline? This is exploratory development work, not circuit discovery or confirmatory generalization.

Use all 16 previous IOI development rows, fixed GPT-2 revision and official Transformers 4.49.0, CPU float32/eager, four threads, batch1. Select A=L8H10, B=L8H6, C=L9H9: top3 by s2_flip END mean gain in published102. Selection uses already-seen development data. Do not claim unbiased selected-head importance. Freeze all seven nonempty subsets A/B/C/AB/AC/BC/ABC and all three modes zero/mean_abc/resample_abc before inference. Intervention is only the last prompt token's preprojection head output z; NOT removal of a head at all positions or its weights. Unintervened downstream computations run freely.

ABC reference bank: for each of two template structures, replace the first, second and third name occurrences with all six permutations of Michael/Christopher/Jessica. Names are distinct, single-token; no repeated subject identity, no unique IO target. This removes repetition rather than giving these references correctness labels. Twelve reference sentences total, six per template. Mean is calculated per template at END. Resample is one of these six frozen by Python random.Random(103), mappings in config. The same donor is used for all selected heads/subsets for a recipient. This is one fixed donor assignment, not a Monte Carlo estimate over donors. Reference bank is construction, not final-test data.

For each mode/subset compute raw IO-minus-S logit difference D, drop D_clean-D_ablated, IO probability and vocabulary top1. Primary contrast: zero versus mean_abc for AB drop and I_AB=drop_AB-drop_A-drop_B. Secondary: all single, pair, triple effects and conditional C drop after AB=drop_ABC-drop_AB, plus contrast with single C. No clipping and no winner selection. Report paired row values; no IID CI for related16rows. Log replacement-to-clean vector distance and norm; these are perturbation magnitude diagnostics, not proof of being in/out of distribution. Nonadditivity may reflect residual downstream adaptation, layer norm/nonlinearity, saturation or redundant computation; it does not identify a compensating head or pathway.

Controls: selected-node clean-self replacement identity (all3 jointly), empty-set identity, official full GPT2 LM versus last-token readout (<0.001), independent postprojection delta versus preprojection overwrite for every mode/all3 (<0.001). Check only selected END slices changed, no weight edits. Every input/resources/code hash is frozen in plan.json. No output cache used. Smoke one target plus complete12-reference bank, then all16; budget300s/4GiB. Full run starts only if smoke projected budget passes. No training, generation, BOS, truncation, TransformerLens runtime or heldout names/templates inference. Full paper's ABC sampling and circuit are not reproduced.
