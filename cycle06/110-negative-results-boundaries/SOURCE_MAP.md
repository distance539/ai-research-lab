Rank formula: G.V.Cormack, C.L.A.Clarke, Stefan Büttcher (2009), [Reciprocal Rank Fusion outperforms Condorcet and individual Rank Learning Methods](https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf), p1 Eq1. This is a paper, not a code repository; no SHA claim. Retrieved PDF hash in upstream_verification.json, ACM copyright, PDF not redistributed. `baseline_run.blend_report` independently adapts the formula to prior RRF ranking plus CE ranking on the same50documents; it is not a claim to replicate original systems.

`statistics_report.groups_from_gold` (union-find), `main` (paired ratio-of-sums component bootstrap, query sensitivity, quantiles, leave-one-group-out) are independent teaching implementations. There is no official SciFact clustering module being copied. Method background: [SciPy1.13.1 bootstrap documentation](https://docs.scipy.org/doc/scipy-1.13.1/reference/generated/scipy.stats.bootstrap.html), paired resampling and percentile method. We explicitly choose percentile rather than SciPy's BCa default. We execute NumPy1.26.4 default_rng/quantile and serialize indices; we do NOT call scipy.stats.bootstrap for cluster sampling. The graph-based grouping is our dependence proxy, not a method asserted by SciPy docs or guaranteed coverage. No implementation source from SciPy is copied.

`audit_statistics.check` independently uses graph BFS, standard-library sums and manual linear interpolation; it checks60000 replicate means and12interval endpoints. `test_statistics.py` injects five corruption classes and includes unequal-size estimand control.
