# Frozen protocol — 2026-10-21

Question: does the fixed END-only ABC set approximate the full model and its responses to removing any subset K of ABC?
A=L8H10, B=L8H6, C=L9H9, zero-based. Selected in102, frozen in103/104. No reselection.
Universe U is only the 144 attention head outputs at END. Background B includes every earlier token, all MLPs, embeddings, residual connections, output projection biases and layer norms. These are NEVER removed. The local retained system C* = B plus three END nodes is NOT a complete circuit.
For full-minus-K remove K; for retained-minus-K remove (U minus ABC) union K. Remaining head values are recomputed during each intervention (not clamped to clean). Use the same reference replacement in both arms.
Two prespecified replacements: zero; mean of six permutations of Michael/Christopher/Jessica at three name positions for each template0..3. This24prompt ABC reference bank has distinct names per prompt and no unambiguous IO label. Mean taken at END in the unmodified model, separately per template; no target outcome used. Names in reference bank are a narrow deliberate distribution, not an exhaustive marginalization.
All256 samples from104 already observed, four64-row name/template cells. This entire experiment is exploratory. No new confirmation set or iid CI. Model/revision/tokenizer/threads/batch/precision unchanged from104. Seed105; no stochastic decoding/training. Model and tokenizer resources are independently SHA-checked on every entry.
Enumerate K='',A,B,C,AB,AC,BC,ABC. Primary: absolute gap of group mean IO-S logits at empty K, plus mean absolute row residual. Secondary: each subset gap, largest of all eight (reported as exhaustive descriptive search, not an independent confirmation), positive signs and vocabulary top1. No arbitrary pass threshold for scientific fidelity. Worst counterexample is largest absolute empty-K residual within group/mode, ties lowest id.
Budget: CPU4threads, peak RSS4GiB,900s; one-row smoke estimates full runtime before running all256.24 reference forwards +31 unique scored conditions +4 control forwards per target. Self-patch all144 END nodes and empty patch must match clean exactly. Retained-empty-K replay via postprojection delta must agree full logits within0.001. Assertions also ensure untouched slices identical, single-token names, append-token identity, no truncation.
Save every candidate logit, argmax, IO probability, prompt/token identity, four replacement means, reference prompts, runtime/environment and stages. Independent stdlib arithmetic audit plus model replay checks; retain any failures. Zip excludes weights/cache/venv/private paths. Use pinned public code and official model; TransformerLens/EasyTransformer runtime is not used. No inference on any new heldout samples.
